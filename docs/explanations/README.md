# 原理解释

本项目当前**没有独立的原理解释文档**。

## 为什么空着

「为什么这样设计」的内容目前分布在两处，各有更适合的归宿：

| 现有内容 | 当前位置 | 为什么不搬到这里 |
|---|---|---|
| 请求链路的分层与顺序 | [`architecture/REQUEST_PIPELINE.md`](../architecture/REQUEST_PIPELINE.md) | 它是**当前架构描述**（「现在长什么样」），不是背景综述 |
| 主干-支干的结构理由 | [`pipeline/README.md`](../../src/main/java/com/kaixuan/copilot_ollama_proxy/pipeline/README.md) | 它在代码里，能跟 `git pull` 走——这是刻意的安排 |
| 各项决策的取舍 | [`adr/`](../adr/) | ADR 是**当时的**决策记录；解释文可以综合多篇 ADR 讲「故事」，但不能充当决策证据 |

## 什么时候会有内容

当出现**跨多个 ADR 的来龙去脉**需要讲清楚时——比如「请求转换系统为什么长成今天这样」，
需要综合 ADR-0003（翻译口径）、ADR-0007（规则引擎边界）、ADR-0008（鉴权头装配）三篇
才能讲完整的故事。这类综述放这里，而不是塞进任何单篇 ADR。
