# 操作指南

本项目当前**没有面向用户的操作指南**。

## 为什么空着

`guides/` 的职责是「怎么做 X」——面向任务的步骤序列。COSP 的使用方式只有一条：

```bash
./mvnw spring-boot:run
```

然后浏览器打开 `http://localhost:11434`，用 `root` / `root` 登录管理后台配置供应商。
这属于**项目介绍**（归仓库根 `README.md`），不构成需要单独文档化的操作流程。

## 什么时候会有内容

出现下列情况时在本文档目录下新增指南（文件名小写 kebab-case）：

- 复杂配置流程（如多供应商 + 请求规则的组合配置）
- 故障排查步骤（「模型列表不出现怎么办」）
- 部署方案（如 Docker 化、反向代理配置）
