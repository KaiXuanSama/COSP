# ADR-0024: 叠放预览与规则区采用 2:3 宽度比例

- **状态**：Accepted
- **日期**：2026-11-07
- **取代**：部分取代 [ADR-0021](./adr-0021-stacked-diff-preview.md) 中组内 1:2 布局的约定；其他组件和交互边界不变。
- **相关**：[RFC 试用反馈](../working/rfcs/2026-11-06-request-body-stacked-diff.md#stacked-diff-ui-feedback)

## 背景

规则组接入后，用户实际试用发现 1:2 比例让左侧叠放文本过于拥挤，尤其加入编辑行号后，
长 JSON 的阅读空间进一步减少；用户明确要求将左、右比例改为 2:3。

## 决策

**桌面布局将叠放预览与规则区宽度调整为 2:3。** 最小高度、右侧驱动等高、左右错位和
窄容器纵排均保持原约定。两侧都展示不会换行的逻辑行号，露出边缘只保留无文字的切换入口。

## 后果

- 预览获得更多横向空间，行号和 JSON 正文更易阅读。
- 右侧规则区相应缩窄，依靠现有条件行换行和窄容器适配保持可用。

## 备选方案

继续 1:2 仅压缩行号或字体：会牺牲可读性，且无法解决叠放内容区域本身偏窄的问题。
